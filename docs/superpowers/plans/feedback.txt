### 一、 关键算法与业务逻辑微调（高优先级）

#### 1. `Task 3` 实时行情涨跌幅计算接口（`data_loader.py`）

* **隐患**：计划中使用 `ak.stock_zh_index_daily_em(symbol=spot_code)` 获取实时数据。但该接口返回的是历史日线序列（最新一行通常是上一交易日的收盘价，或者盘后才更新），**在盘中（如 10:30）无法获取到当天的实时最新价/涨跌幅**。


* **建议修正**：对于盘中实时涨跌幅，推荐使用专门的轻量级实时接口，或者使用新浪/东财的 Single-Stock 接口，例如：


```python
def get_realtime_change(spot_code: str) -> float:
    """
    获取单指数盘中实时涨跌幅（轻量级）
    spot_code: 'sz399006' 或 'sh000922'
    """
    try:
        # 使用 ak.stock_zh_a_spot_em 或新浪实时接口
        # 以 ak.stock_zh_index_spot_sina 为例，速度极快且实时
        df = ak.stock_zh_index_spot_sina(symbol=spot_code)
        if not df.empty:
            return float(df.iloc[0]['涨跌幅']) / 100.0  # 返回如 0.0125 表示 1.25%
        return 0.0
    except Exception as e:
        st.warning(f"获取实时行情失败 ({spot_code}): {e}")
        return 0.0

```



#### 2. `Task 6` 回测信号去重逻辑的边界问题（`backtester.py`）

* **代码隐患**：在 Step 3 中，使用 `result['signal'] = result['signal'].replace(0, method='ffill').fillna(0)`。


* **问题**：如果初始的前 N 天比值全部处于“中性区间”（`signal=0`），`ffill` 无法填充前面的 0。另外，在 Pandas 2.1+ 中，`replace(0, method='ffill')` 已被废弃，会抛出 `FutureWarning`。




* **建议修正**：


```python
# 规范的持仓前向填充方式
result['signal'] = result['signal'].replace(0, None).ffill().fillna(0)

```



#### 3. `Task 8` Plotly 阈值线图表属性（`app.py`）

* **问题**：在 `render_ratio_chart` 中，`fig.add_hline(y=STRATEGY_CONFIG['low_percentile'])` 直接将 0.10 (10%) 当作 Y 轴画线。


* **分析**：Plotly 的 Y 轴绘制的是**比值（Ratio，如 0.45）**，而 `0.10` 是**百分位数（Percentile）**。直接画 `y=0.10` 的横线会导致阈值线落在图表最底部，与实际比值序列数量级不匹配！




* **建议修正**：


* **方案 A**：折线图画 **滚动百分位数**（Y轴为 0~1），此时画 `y=0.10` 和 `y=0.90` 虚线。
* **方案 B（推荐）**：折线图画 **比值**，但阈值线使用 `percentiles` 对应的动态比值上限/下限：
```python
# 计算历史各个时间点的 10% 和 90% 滚动比值阈值
rolling_low = merged_data['ratio'].rolling(750).quantile(0.10)
rolling_high = merged_data['ratio'].rolling(750).quantile(0.90)

# 将动态阈值作为两条虚线/阴影带画在图中
fig.add_trace(go.Scattergl(x=merged_data['date'], y=rolling_low, name='抄底边界 (10%)', line=dict(dash='dash', color='red')))
fig.add_trace(go.Scattergl(x=merged_data['date'], y=rolling_high, name='逃顶边界 (90%)', line=dict(dash='dash', color='green')))

```
