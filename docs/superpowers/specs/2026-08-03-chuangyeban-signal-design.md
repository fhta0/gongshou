# 创业板/中证红利比值信号系统设计

## 概述

本系统是一个基于 Streamlit 的量化信号工具，用于监控创业板指数与中证红利指数的比值，并根据历史极值区间提供抄底/逃顶信号。

### 核心理念

- **创业板指数**：代表高弹性、高成长的进攻型资产
- **中证红利指数**：代表稳定分红、防御型的现金流资产
- 两个指数具有明显的负相关性，比值在历史上有清晰的极值区间

### 信号规则

| 条件 | 信号 | 含义 | 操作建议 |
|------|------|------|----------|
| 比值 ≤ 0.3 | 🔴 抄底 | 创业板极度低估，市场只相信眼前的现金 | 买入创业板指数，卖出中证红利指数 |
| 比值 ≥ 0.7 | 🟢 逃顶 | 创业板极度高估，科技/成长交易极度拥挤 | 卖出创业板指数，买入中证红利指数 |
| 0.3 < 比值 < 0.7 | 🟡 中性 | 比值处于正常区间 | 持有观望 |

1. 启动时加载历史数据（缓存 1 小时）

## 数据层设计

### 指数代码

- 创业板指数：`399006`（深交所）
- 中证红利指数：`000922`（上交所）

### AKShare 接口

| 用途 | 函数 | 说明 |
|------|------|------|
| 历史日线 | `ak.index_zh_a_hist(symbol="399006")` | 返回日期、开盘、收盘、最高、最低、成交量 |
| 实时行情 | `ak.stock_zh_index_spot_em()` | 返回所有指数实时行情，过滤目标指数 |

### 数据获取逻辑

```python
@st.cache_data(ttl=3600)  # 缓存1小时
def load_historical_data(symbol):
    """加载历史日线数据"""
    df = ak.index_zh_a_hist(symbol=symbol)
    return df[['日期', '收盘']].rename(columns={'日期': 'date', '收盘': 'close'})

def get_realtime_quote():
    """获取盘中实时报价"""
    df = ak.stock_zh_index_spot_em()
    # 过滤出创业板和中证红利的最新价
    chuangyeban = df[df['代码'] == '399006']['最新价'].values[0]
    hongli = df[df['代码'] == '000922']['最新价'].values[0]
    return chuangyeban, hongli
```

### 数据合并与比值计算

```python
# 合并两个指数的历史数据
merged = pd.merge(chuangyeban_df, hongli_df, on='date', suffixes=('_cy', '_hl'))
```

### 缓存策略

- 历史数据：缓存 1 小时（每日收盘后更新一次即可）
- 实时报价：不缓存，每次刷新时重新获取

## 自动刷新机制

```python
import time
from datetime import datetime

def is_trading_hours():
    """判断是否在盘中交易时间"""
    now = datetime.now()
    # 周一到周五，9:30-11:30, 13:00-15:00
    if now.weekday() >= 5:
        return False
    hour, minute = now.hour, now.minute
    morning = (hour == 9 and minute >= 30) or (hour == 10) or (hour == 11 and minute <= 30)
    afternoon = (hour == 13) or (hour == 14)
    return morning or afternoon

# Streamlit 自动刷新
if is_trading_hours():
    time.sleep(300)  # 5分钟 = 300秒
    st.rerun()
```

### 回测算法

```python
def backtest_signals(df, threshold_low=0.3, threshold_high=0.7):
    """回测历史信号的实际收益"""
    signals = []
    
    for i, row in df.iterrows():
        if row['ratio'] <= threshold_low:
            # 抄底信号：买入创业板，持有N天
            future_returns = calculate_future_return(df, i, days=20)
            signals.append({
                '日期': row['date'],
                '信号': '抄底',
                '比值': row['ratio'],
                '创业板20日收益': future_returns['cy'],
                '红利20日收益': future_returns['hl']
            })
        elif row['ratio'] >= threshold_high:
            # 逃顶信号：卖出创业板，买入红利
            future_returns = calculate_future_return(df, i, days=20)
            signals.append({
                '日期': row['date'],
                '信号': '逃顶',
                '比值': row['ratio'],
                '创业板20日收益': future_returns['cy'],
                '红利20日收益': future_returns['hl']
            })
    
    return pd.DataFrame(signals)
```

### 回测展示

- 表格：每次信号触发的日期、比值、后续收益
- 统计：信号触发次数、平均收益、胜率
- 图表：按信号类型分组的收益分布

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| AKShare API 请求失败 | `st.error()` 显示错误，保留上次缓存数据 |
| 非交易日/非交易时间 | 显示"市场已收盘"，使用最后已知数据 |
| 历史数据缺失 | 跳过缺失日期，不影响比值计算 |
| 实时报价获取失败 | 显示"--"，不触发自动刷新 |
