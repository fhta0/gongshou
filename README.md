# 双动量信号系统

创业板/中证红利双动量轮动策略的实时信号与历史回测工具。

**当前版本**: v1.2.0

## 策略逻辑

### 核心策略：双动量轮动

- **相对动量**：比较两指数的 20 天平滑动量（多窗口平滑：10/20/40 天），选择更强的一方
- **绝对动量**：胜者动量需超过无风险利率（1.5% 年化），否则空仓
- **冷却期**：信号切换后 12 天内不允许再次切换（防频繁交易）
- **波动率目标**：根据实现波动率动态调整仓位（目标 14% 年化波动率）

### 估值过滤（v1.2.0 新增）

- **估值硬约束**：当推荐买入的指数 PE 百分位 > 80% 时，改为空仓（避免高估追涨）
- **数据来源**：乐咕乐股（创业板50、上证红利的历史 PE 数据）
- **百分位计算**：使用扩展窗口（至少 100 天数据）
- **UI 展示**：实时显示 PE 值和估值状态（🟢低估 / 🟡适中 / 🔴高估）

**为什么需要估值过滤？**

纯动量策略会在动量强势时买入，但如果某指数已经明显高估（如 PE 处于历史高位），追涨风险较大。估值过滤通过设置硬约束，避免在高估值区域买入。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

访问 http://localhost:8501

## 部署到 Streamlit Cloud

1. Fork 本仓库到你的 GitHub
2. 访问 [share.streamlit.io](https://share.streamlit.io)
3. 点击 "Deploy an app"
4. 选择仓库 `gongshou`，分支 `master`，主文件 `app.py`
5. 点击 "Deploy"

## 技术栈

- Python 3.10+
- Streamlit
- akshare（数据源：新浪、中证指数、乐咕乐股）
- pandas / numpy
- plotly（可视化）

## 项目结构

```
app.py          # Streamlit 主入口
config.py       # 策略参数配置（含版本号）
data_loader.py  # 数据加载与缓存（含 PE 数据）
strategy.py     # 信号生成逻辑（含估值过滤）
backtester.py   # 历史回测引擎
tests/          # 单元测试
```

## 配置说明

关键参数在 `config.py` 中配置：

```python
STRATEGY_CONFIG = {
    "momentum_window": 20,              # 主窗口（用于无风险门槛计算）
    "momentum_windows": [10, 20, 40],   # 多窗口平滑
    "risk_free_rate": 0.015,            # 年化无风险利率 1.5%
    "cooldown_days": 12,                # 信号冷却期
    
    # 波动率目标
    "target_vol": 0.14,                 # 目标年化波动率 14%
    "vol_lookback": 60,                 # 实现波动率回看窗口
    
    # 估值过滤（v1.2.0 新增）
    "apply_pe_filter": True,            # 是否启用估值过滤
    "pe_percentile_threshold": 0.80,    # 高估阈值（80% 分位）
    "pe_window": 100,                   # PE 百分位计算窗口
}
```

## 注意事项

- 数据来自公开 API（新浪、中证指数、乐咕乐股），可能存在延迟或缺失
- PE 数据源为乐咕乐股，创业板指使用创业板50替代，中证红利使用上证红利替代
- 本工具仅供研究参考，不构成投资建议
- 冷却期状态在 Streamlit Cloud 上为会话级别（重启后重置）
